# Бот сервиса ремонта бытовой техники

Python 3.12+, python-telegram-bot, SQLite. Бот работает в личных сообщениях через long polling; публичный сервер и webhook не нужны.

## Запуск

```bash
cd /workspace/bot-tech
python -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env` (именно `.env`, не `.evn`):

- `BOT_TOKEN` — токен от @BotFather.
- `ADMIN_IDS` — числовые Telegram ID администраторов через запятую.
- `CONTACTS_TEXT` — телефон, адрес, часы работы сервиса.
- `REVIEWS_TEXT` — текст раздела отзывов; `REVIEWS_URL` — необязательная HTTPS-ссылка.
- `WELCOME_PHOTO` — путь к приветственному JPG/PNG. По умолчанию используется иллюстрация в `assets/welcome.png`; можно заменить своим фото.

```bash
.venv/bin/python bot.py
```

Чтобы узнать ID, временно запустите бота без `ADMIN_IDS`, откройте его и отправьте `/myid`. Затем заполните `ADMIN_IDS` и перезапустите процесс. Каждый администратор должен сначала открыть бота и нажать `/start`, иначе Telegram не разрешит боту писать ему первым. Не запускайте два процесса с одним токеном.

В облачной среде для работы Telegram требуется разрешить HTTPS-домен `api.telegram.org` в настройках сети. Сохраняйте штатные прокси и проверку TLS. Токен храните только в `.env` или безопасных переменных среды, не добавляйте в Git.

## Сценарий

1. `/start`: приветственное изображение, запрос собственного контакта кнопкой или номера текстом. Номер проверяется по формату, владение введённым вручную номером не подтверждается.
2. Описание проблемы и модели одним текстовым сообщением (до 2000 символов). Повторный текст заменяет описание. «Далее» сохраняет заявку; описание можно пропустить.
3. Меню: «Поломка» создаёт новую заявку, «Запись» собирает желаемые дату и время, «Контакты» и «Отзывы» показывают настроенные данные. Запись подтверждается мастером отдельно.

`/cancel` возвращает в меню после первой завершённой заявки. `/start` начинает анкету заново; старые заявки сохраняются.

Администраторы получают уведомления о `/start`, заявках с телефоном и проблемой, пожеланиях по записи. `/admin` показывает статистику, историю входов и заявки с постраничной навигацией. Время отображается по Москве. Telegram не сообщает боту о простом открытии чата: вход регистрируется при команде `/start`.

Сведения сохраняются в `data/bot.sqlite3`, включая незавершённое описание. Делайте защищённые резервные копии БД и ограничивайте доступ к ней: она содержит персональные данные. При недоставленном уведомлении заявка остаётся в админ-панели; автоматической очереди повторной доставки нет.

## Проверки

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют анкету, сохранность описания после переоткрытия БД, запись, отказ чужому контакту, формат телефона и защиту админ-панели. Для проверки Telegram после настройки токена пройдите `/start` с клиентского аккаунта, отправьте телефон и описание, нажмите «Далее», затем проверьте уведомление и `/admin` с аккаунта администратора.

Используйте существующий checkout; отдельный Git worktree для работы в облачной задаче не требуется. После перезапуска облачной среды запускайте процесс бота заново.

Для администраторов в меню команд вместо `/start` показывается `/admin`. Первоначальная кнопка Telegram «Начать» также открывает админ-панель для ID из `ADMIN_IDS`. Обновление меню применяется при запуске бота.
